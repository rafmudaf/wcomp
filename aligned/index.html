Wake model comparisons

wcomp runs the same windIO wind-farm cases through FLORIS, FOXES, and PyWake so the same wake model can be compared directly across independent implementations. Every chart on this site reads from a versioned dataset generated with wcomp's solver interfaces.

Generated 10/31/2026 against FLORIS 4.6.6, FOXES v1.9.3, and PyWake2.6.21.dev30+g7b7ffbca8.

Framework details

  • With the rotor sampling matched, rotor averaging contributes little. On the offset gaussian velocity deficit field the rotor-average error ranges from 0.1% (FLORIS) to 0.6% (PyWake).
  • Power and thrust tables are reproduced essentially exactly (power within 9e-12 kW, Ct within 1e-15 in range). The one visible difference is FLORIS's Ct, which is clipped by 1e-4 outside the cut-in/cut-out range.

Case comparisons

  • The largest streamwise disagreement is Bastankhah 2016 deflection with four turbines, FLORIS vs FOXES: 1.22 m/s RMSE (13.9% NRMSE).
  • Differences grow with turbine count. Bastankhah 2014 goes from 0.01 m/s RMSE (max over software pairs) with one turbine to 0.64 m/s with four.
